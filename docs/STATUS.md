# Текущее состояние CombatHUD

- Действующая версия: `0.1.0`. Поведение затемнения нижних панелей вне боя принято пользователем в игре; перенос в общий репозиторий не менял Lua-поведение.
- Публичного упакованного релиза пока нет.
- **Следующее согласованное изменение (не реализовано):** показывать весь HUD при потере HP вне боя и постоянно оставлять видимой только HP-полоску при неполном здоровье. Точная UX-семантика и граница приёмки записаны в [REQUIREMENTS.md](REQUIREMENTS.md).
- **Ближайший технический шаг:** прочитать существующие локальные данные/дампы игры, если доступны, и установить подтверждённые источники `current/max HP` и путь HP-полоски внутри HUD. В доступных опубликованных источниках и проверенном runtime-документе этих идентификаторов пока нет. При необходимости сделать один узкий runtime probe после обоснования.
- Production Lua и `VERSION` оставлены без изменений; пользовательский runtime-тест новой функции ещё не проводился.
