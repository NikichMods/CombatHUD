# Текущее состояние CombatHUD

**Принятая стабильная версия — 0.5.0 (2026-11-19).** Пользователь подтвердил
работу в игре. В логе проверено первое открытие с геймпада после клавиатуры.
[Приёмка, точный исходник и хеши](CANDIDATE-0.5.0.md).
[GitHub Release 0.5.0](https://github.com/NikichMods/CombatHUD/releases/tag/CombatHUD-v0.5.0).

## Принятое поведение

- Вход в бой возвращает полную яркость за 1 с. Обычный выход запускает задержку 1,5 с и затухание за 1 с до 20%.
- Урон сразу раскрывает HUD. HP и три быстрых предмета остаются яркими 6 с после урона или выхода из боя раненным. Частичное лечение не продлевает таймер.
- Interact временно раскрывает весь HUD. Модификатор навыков раскрывает две правые группы, при отпускании они затухают за 1 с.
- Открытие штатного выбора чаровитов с геймпада раскрывает его панель на 1,5 с с затуханием за 1 с. Раннее закрытие сразу возвращает обычную policy.
- Штатное скрытие сохраняет приоритет. CombatHUD работает в одном GameThread-цикле с номинальным интервалом 50 мс. [Контракт планировщика](SCHEDULER_READINESS.md).

## Границы и откат

Видимая клавиатурная раскладка чаровитов, live rebinding и focus-loss отдельно
не подтверждены. Короткий урон с восстановлением между замерами может быть
пропущен. [Принятая 0.4.1](CANDIDATE-0.4.1.md) сохранена для отката вне
loader. Откат выполняется при закрытой игре с проверкой хешей.
