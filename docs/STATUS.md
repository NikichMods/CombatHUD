# Текущее состояние CombatHUD

**Стабильная версия — 0.2.0**, явно принята пользователем 2026-10-27 после игрового теста урона, лечения, боя и меню. Продвинута в `main`; тег `CombatHUD-v0.2.0` опубликован. [GitHub Release](https://github.com/NikichMods/AsterigosMods/releases/tag/CombatHUD-v0.2.0) опубликован 2026-10-27. ZIP и SHA-256 скачаны по публичным ссылкам и побайтно совпадают с подготовленными файлами. Исходный payload-коммит — `ca342e33442a11b46a9ab30ed8e8cd796c9a8d60`, стабильный тег — `CombatHUD-v0.2.0`. Хеши, установка и сессия — [запись 0.2.0](CANDIDATE-0.2.0.md).

## Принятое поведение

- Вход в бой: плавное появление всего управляемого HUD за 1 секунду. Выход: задержка 1,5 секунды, затем переход за 1 секунду до 20%.
- Обнаруженное уменьшение HP немедленно раскрывает обе группы. Пока HP неполное, здоровье и все три быстрых слота 1/2/3 остаются яркими; остальные элементы приглушаются независимо.
- Полное лечение запускает собственную задержку здоровья и предметов; таймер остальных элементов не перезапускается.
- Штатное скрытие HUD сохраняется. Меняются только RenderOpacity адресно проверенных целей, не характеристики, управление, Visibility или общие menu ancestors.

## Доказательства и пределы

Игровой лог 2026-10-27 23:20–23:24 МСК идентифицирует 0.2.0, owning hilda_BP_C и 17 целей; он подтверждает автоматические damage/combat/heal переходы без ошибок CombatHUD. Внешний вид и меню подтверждены пользователем. Python 3.12.14 / lupa 2.8: все доступные офлайн-тесты PASS; дополнительные lifecycle/failure сценарии покрыты mock-тестами, не объявляются отдельно проверенными в игре.

**Чаровиты:** проверка видимых клавиатурных/геймпадных элементов и смены input layout отложена до естественного открытия в сохранении. Не менять сохранение, не открывать их специально и не начинать отдельное исследование без возникшей проблемы. Native скрытая ветка сохраняется; непроверенная поддержка не заявляется. Это сознательно принятая граница версии, не блокировка её принятия.

Предыдущая принятая 0.1.0 сохранена вне загрузчика в ignored `.local/candidates/CombatHUD-0.2.0/previous-payload/Scripts/` основного checkout; оба хеша повторно проверены при продвижении. Протестированный payload 0.2.0 и исходный архив неизменяемы. Переустановка для продвижения не требуется; установленные Lua не менялись.

Исторические исследования, ручные эксперименты и их gates сохранены в [VERIFIED_RUNTIME.md](VERIFIED_RUNTIME.md) и `research/`; они не являются текущими задачами. Общие host-находки принадлежат Asterigos-Research. Дальнейшие изменения требуют нового кандидата и обычной приёмки. Проверка чаровитов после естественного открытия остаётся отложенной, независимо от новых задач.

## Согласованное следующее улучшение — без реализации

2026-10-29 пользователь принял два контекстных способа временно повысить яркость: **нажатие переназначаемого действия взаимодействия раскрывает весь HUD**, **удержание переназначаемого модификатора навыков раскрывает только панель боевых навыков**. Нажатие — разовое, с существующей задержкой 1,5 с и fade 1 с; после отпускания навыков — только fade 1 с без задержки. Не добавлять постоянный переключатель, не привязываться к фиксированным кнопкам, не вмешиваться в native меню. Полная семантика и границы записаны в [REQUIREMENTS.md](REQUIREMENTS.md).

**Статический этап выполнен; Interact / skill modifier / targets — OPEN для реализации.** Найдены native input enum/mapping/context/getter контракты, отсутствие NotifyActionInput override у MainPlayerController_BP и две правые skill-группы. У pad asset четыре skill-слота плюс два Image; это ещё не объясняет шесть видимых иконок. Точные выводы, SHA-256 и пределы — [VERIFIED_RUNTIME.md](VERIFIED_RUNTIME.md#контекстные-игровые-действия-и-skill-targets--статический-этап-2026-10-29). Подготовлен приватный read-only observer с offline safety PASS; он не установлен, установка ожидает отдельного явного подтверждения после отказа проверки разрешений. Следующий достаточный шаг — один короткий gameplay/menu/device/focus прогон; production/VERSION/установка 0.2.0 и опубликованный архив не менялись. Диагностический код и dumps не опубликованы.
