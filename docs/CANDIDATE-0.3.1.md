# CombatHUD 0.3.1 — исправление input owner, НЕ принят

**Ветка:** `feature/contextual-hud-reveal`. **Статус:** установлен 2026-10-29 при закрытой игре; ожидается повторный пользовательский игровой тест. Пока **нет runtime PASS**. 0.3.0 остаётся отдельным неизменяемым отклонённым кандидатом; `main`/стабильная 0.2.0 не менялись.

## Причина и точечное изменение

Игровой лог точной 0.3.0 (см. [CANDIDATE-0.3.0.md](CANDIDATE-0.3.0.md)) доказал ошибку `GameGlobal:GetNowInputControllerType()` в `Scripts/main.lua:333`. По подтверждённым observer02/03 сведениям этот getter принадлежит `GenesisPlayerController`. В 0.3.1 вызывается `controller:GetNowInputControllerType()` после проверки controller-ownership. Другой runtime-механизм, UI-цели, семантика Interact и skill-modifier, фейды и HP/combat-политика не менялись.

В mock `GetNowInputControllerType` перенесён в controller; вызов на GameGlobal намеренно бросает ошибку, а adapter-тест проверяет факт вызова метода владельца. `python tools/test.py` **PASS** с Python 3.12 и `lupa==2.8` в независимом sandbox. Это устраняет подтверждённую ошибку владельца, но не доказывает, что все следующие runtime seams работают.
