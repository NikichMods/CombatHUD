# CombatHUD 0.3.1 — исправление input owner, НЕ принят

**Ветка:** `feature/contextual-hud-reveal`. **Статус:** готов к локальной безопасной установке и повторному игровому тесту. Пока **нет runtime PASS**. 0.3.0 остаётся отдельным неизменяемым отклонённым кандидатом; `main`/стабильная 0.2.0 не менялись.

## Причина и точечное изменение

Игровой лог точной 0.3.0 (см. [CANDIDATE-0.3.0.md](CANDIDATE-0.3.0.md)) доказал ошибку `GameGlobal:GetNowInputControllerType()` в `Scripts/main.lua:333`. По подтверждённым observer02/03 сведениям этот getter принадлежит `GenesisPlayerController`. В 0.3.1 вызывается `controller:GetNowInputControllerType()` после проверки controller-ownership. Другой runtime-механизм, UI-цели, семантика Interact и skill-modifier, фейды и HP/combat-политика не менялись.

В mock `GetNowInputControllerType` перенесён в controller; вызов на GameGlobal намеренно бросает ошибку, а adapter-тест проверяет факт вызова метода владельца. `python tools/test.py` **PASS** с Python 3.12 и `lupa==2.8` в независимом sandbox. Это устраняет подтверждённую ошибку владельца, но не доказывает, что все следующие runtime seams работают.

## Следующая приёмочная проверка

1. Только при закрытой игре сохранить проверенную резервную копию текущих установленных файлов вне загрузчика, установить точные три файла нового кандидата и сверить их SHA-256. Прежнюю 0.3.0 и 0.2.0 не перезаписывать как архивы/артефакты; менять лишь активный installed payload по правилам DevRules. Не трогать чужие моды и `mods.txt` без необходимости.
2. Пользователь запускает игру самостоятельно. Убедиться по штатному UE4SS-логу, что загрузилась **0.3.1**, и отсутствует прежняя ошибка `GetNowInputControllerType`. Снять фактическую последовательность регистрации pressed hook и поведение при взаимодействии.
3. Вне боя при полном HP после приглушения нажать текущий Interact в пустом месте — весь управляемый HUD должен стать ярким, подержаться 1,5 с и погаснуть за 1 с. Проверить также другой доступный способ ввода (геймпад / клавиатура).
4. Удержание текущего модификатора навыков должно подсвечивать только две правые skill-группы; отпускание — плавно гасить их за 1 с без задержки. Проверить нативное меню/подтверждение, переключение устройства и отсутствие ложного общего раскрытия.
5. Старые правила combat/damage/heal/partial HP и нативного скрытия должны остаться неизменными. Переназначение вживую и focus-loss проверять при возможности, не подменяя отсутствие проверки декларацией поддержки. Чаровиты остаются отложенными до естественного открытия.
6. Пользователь закрывает игру. Codex сохраняет полный лог/точный installed payload, докладывает о runtime результате; затем документирует доказательства и отправляет коммит в feature-ветку. Не менять production автоматически по факту ошибки, не сливать в `main`, не делать релиз и не объявлять принятой без явной пользовательской оценки.
